# Stage 2 — Global Layout, Navigation & Mobile Framework

Status: implemented.

## Added

- Fixed premium global header with compact-on-scroll state.
- Waterline micro-motif integrated into navigation shell.
- Responsive desktop navigation and native-dialog mobile menu.
- Persistent mobile conversion bar: Call / WhatsApp / Check Dates.
- Global footer with property identity, address, navigation and booking CTA.
- Skip-to-content accessibility affordance and global focus-visible treatment.
- Public route shells for `/rooms`, `/book`, `/virtual-tour`, `/arrival` so the global navigation can be validated before those experiences are built.
- Homepage anchor placeholders for future sections.

## Locked behavior

- Desktop keeps navigation quiet, centered and editorial.
- Mobile uses a full-screen Lake Deep menu and a persistent bottom conversion surface.
- Booking remains prominent without turning the site into a banner-heavy OTA interface.
- Motion is CSS-based at this stage; signature animation libraries remain reserved for later stages.

## Not built in Stage 2

- Hero experience.
- Booking search component.
- Terrace scroll storytelling.
- Room experience.
- Restaurant section.
- Full booking flow.
- Marzipano viewer.

These remain assigned to their later stages.
